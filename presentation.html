HARDENING & AUDIT

Stealth Fixes & Security Audit

Shipped This Week

  • Nuclei template auto-update gated — no phone-home to GitHub before every scan (config: update_templates: false)
  • Nuclei timeout scaling fixed — real target count drives timeout, no more silent 5-min kills on large scans
  • Binary path resolved once at init — PATH changes mid-daemon can't break scans
  • Dead config keys wired — templates_path now honored
  • Deps completed — dnspython (DNS recon) + aiohttp (async cred checking)
  • Windows installer — install.ps1 with PATH-safe tool placement
  • Version + license sync — 1.0.0 everywhere, MIT LICENSE added

Audit Findings

  • Default cred admin/hostvigil recreated at startup — provision at first boot
  • Session-only auth — API keys exist (enterprise.py) but aren't wired into the dashboard
  • No CSRF tokens on state-changing routes
  • Rate-limit lockout is per-IP, in-memory — bypassable across IPs/restarts
  • Container runs as root with NET_RAW/NET_ADMIN + host networking
  • Dead modules — scheduler.py, enterprise_pipeline.py, plugins.py, pcap_export.py never wired
  • Dormant config — pipeline.* 100% dead; stealth YAML keys mostly ignored

Positives: no command injection · no SQL injection · parameterized queries throughout · WAL mode everywhere · no shell=True
